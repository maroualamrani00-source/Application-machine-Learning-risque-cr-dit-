# Credit Risk Streamlit Application

## Description
Cette application Streamlit permet l’analyse du risque de crédit à partir d’un jeu de données.
Elle inclut les étapes suivantes :
- Exploration des données
- Nettoyage
- Modélisation
- Évaluation du modèle
- Prédiction

---

## Prérequis
- Python 3.10 ou supérieur
- pip

---

## Installation

1. Décompresser le projet
2. Ouvrir un terminal dans le dossier du projet

Installer les dépendances :
```bash
pip install -r requirements.txt
